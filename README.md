# LAAS butiksskärm

Stående kiosksida (1080×1920) för butiksskärmar. Byt innehåll i `playlist.json` (höj `version`), lägg nya filer i `media/` med nytt filnamn. Skärmen uppdaterar sig själv inom ~2 min. `?debug=1` visar storlek, `?mute=1` stänger av ljud, `?rotate=90` roterar om Android inte är vriden.
